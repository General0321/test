# XProbe 通用扫描器 UI 设计指南

> **设计目标**: 让复杂的功能变简单易用  
> **设计日期**: 2025-10-01

---

## 🎯 设计原则

### 1. 渐进式披露（Progressive Disclosure）
- 默认显示基本选项
- 高级功能折叠隐藏
- 新手友好，专家灵活

### 2. 智能默认值
- 去重颗粒度：AUTO（自动检测）
- 注入策略：Replace（最常用）
- 条件操作符：OR（最宽松）

### 3. 实时反馈
- 配置错误立即标红提示
- 智能建议显示推荐值
- 预览功能展示效果

### 4. 一致性
- 所有下拉框使用相同样式
- 所有按钮使用统一图标
- 配色方案保持一致

  Ctrl/Cmd + S    - 保存规则
  Ctrl/Cmd + F    - 搜索规则
  Ctrl/Cmd + E    - 导出选中规则
  Ctrl/Cmd + I    - 导入规则

编辑器快捷键:
  Tab             - 下一个字段
  Shift + Tab     - 上一个字段
  Ctrl/Cmd + T    - 测试当前规则
  Esc             - 取消编辑

列表快捷键:
  ↑/↓            - 上/下选择
  Space          - 启用/禁用
  Delete         - 删除选中规则
  Enter          - 编辑选中规则
